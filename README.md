# SMARA — The Unfinished City

An asymmetric real-time strategy game concept of the Mauritanian resistance to French colonization, 1902–1934.

**Live showcase:** https://scriptssniper.github.io/rts-mauritania/

Point-control RTS · no base building · wells, herds and tribal allegiance · thirst attrition · Godot 4 · concept stage.

## Repository layout

- `docs/` — GitHub Pages showcase site
- `RESEARCH_campaign_history.md` — historical research backbone (1902–1934), with source-conflict register
- `CHARACTERS.md` — character and faction design bible
- `art/` — concept portraits and placeholder art

## Design pillars

1. **Wells are resources** — capture-point economy of wells, oases, pastures, caravan routes
2. **Herds are economy** — mobile, raidable wealth; caravans as resource convoys
3. **Allegiance is recruitment** — tribes, not barracks
4. **The borj lattice** — France extends a web of desert forts, post by post
5. **The rezzou** — the lightning camel raid, and its colonial mirror
6. **Thirst** — every unit decays away from friendly water

Historical basis: Library of Congress *Mauritania: A Country Study*, French/English Wikipedia, Persée academic history, Gouraud's 1910 memoir. Source conflicts are flagged, not smoothed over.
